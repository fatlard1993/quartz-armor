# Quartz Armor

A Fabric mod that adds a full set of armor crafted from smooth quartz blocks. It's a cheap, early armor tier that sits between iron and diamond: easy to get from the Nether, the easiest armor in the game to enchant well, and fragile enough that it wears out fast.

## Features

- Helmet, chestplate, leggings, and boots crafted from smooth quartz blocks using standard vanilla armor crafting patterns
- More protection than iron, less than diamond
- A little armor toughness, where iron has none
- Triple the enchantability of diamond, the highest of any armor, making these pieces easy to enchant well
- Very low base durability: the price of a set this cheap
- Repairable with smooth quartz blocks
- Accepts armor trims, shown on the icon as well as when worn
- Added to the vanilla Combat creative tab

### Armor Stats

| Stat | Iron | Quartz | Diamond |
|------|------|--------|---------|
| Helmet Defense | 2 | 2 | 3 |
| Chestplate Defense | 6 | 7 | 8 |
| Leggings Defense | 5 | 5 | 6 |
| Boots Defense | 2 | 2 | 3 |
| **Total Defense** | **15** | **16** | **20** |
| Armor Toughness | 0 | 1.0 | 2.0 |
| Helmet Durability | 165 | 110 | 363 |
| Chestplate Durability | 240 | 160 | 528 |
| Leggings Durability | 225 | 150 | 495 |
| Boots Durability | 195 | 130 | 429 |
| Enchantability | 9 | 30 | 10 |

## Pandorical

Quartz Armor goes on the server only, and **Pandorical is required there and on every player's client**: the armor pieces are new items, and a client without Pandorical has no entry for them.
